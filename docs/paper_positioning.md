# Paper Positioning

## Recommended Title

EvoScientist-Mamba: Self-Evolving Neural Architectures for Autonomous Scientific Agents

Alternative:

NeuroEvolutionary Agents: Self-Adaptive Mamba Architectures for Efficient Long-Horizon Reasoning

## Main Research Problem

Current LLM agents have fixed neural substrates. They can use tools and memory, but cannot evolve their internal architecture.

## Proposed Method

Evolutionary Neural Substrate Search (ENSS):

Task -> Architecture Genome -> Evaluation -> Evolution -> Improved Agent

## Main Contributions

1. Task-conditioned neural architecture evolution.
2. Adaptive Mamba memory substrate for long-context agents.
3. Closed-loop self-improving agent optimization.

## Target Venues

Potential targets:
- CCF-C AI conferences
- SCI AI journals
- arXiv preprint

The work should emphasize methodology rather than engineering integration.
