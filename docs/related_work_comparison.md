# Related Work Comparison

| Area | Existing Work | Limitation | EvoMamba-Agent Difference |
|---|---|---|---|
| AlphaEvolve | LLM evolutionary algorithm discovery | Program/algorithm focus | Evolves neural cognitive architectures |
| Traditional NAS | Static architecture search | Offline optimization | Online task-conditioned adaptation |
| Mamba models | Efficient sequence modeling | Fixed architecture | Evolvable memory substrate |
| Agent frameworks | Reasoning + tools | Fixed neural backbone | Self-modifying architecture |

## Positioning

The contribution is not combining Mamba and evolution. The contribution is introducing architecture evolution as an agent capability.
