# Limitations（Phase-21 终版）

1. **单一模型家族**：全部实验基于 Qwen2.5-Instruct（1.5B 与 7B）。
   任务条件化偏好是否跨家族成立未知。
2. **紧凑离散空间**：论文主体空间为 48 有效表型（结构化空间更大但
   搜索仍受小 dev 区间约束）。小样本搜索存在过拟合风险（Phase-20 已观察到
   dev 偏好 ≠ holdout 泛化）。
3. **prompt 级推理策略**：reasoning 基因通过指令模板实现，未微调推理模块。
4. **指标敏感性**：QASPER 的答案提取对标记格式敏感（Phase-21 诊断显示
   7B 的 "collapse" 部分为提取失配）；跨基准能力比较应谨慎。
5. **3 分类天花板**：PubMedQA 的 yes/no/maybe 结构限制了能力区分度。
6. **单一适应协议**：基底适应仅 30 步下一嵌入预测；继承证据为附录级。
7. **成本模型**：效率为参数量足迹 + prompt 词数代理；跨骨干延迟未归一化，
   不作跨骨干延迟比较。
8. **进化优势未证实**：紧凑空间内进化搜索与随机搜索打平（Phase-18），
   进化在本文中仅作为架构生成机制。
