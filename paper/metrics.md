# Evaluation Metrics

## Capability

Measure whether evolved agents improve task-solving ability.

Metrics:

- Accuracy
- Success rate
- Scientific QA score

## Efficiency

Measure deployment cost.

Metrics:

- Latency
- Peak GPU memory
- FLOPs
- Parameter count

## Adaptability

Measure whether agents can adjust to new task distributions.

Metrics:

- Few-shot adaptation improvement
- Cross-task transfer score
- Evolution convergence speed

## Evolution Quality

Measure the search process itself.

Metrics:

- Pareto front improvement
- Number of evaluated candidates
- Search convergence curve
- Diversity of discovered architectures
